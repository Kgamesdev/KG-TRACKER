# Changelog

All notable changes to KG TRACKER are documented here.

## [5.0.0] - 2026-09-09

### Added

- Persistent claimed-games history
- Stable game/store identity for claimed games
- Dark and light themes
- Custom volume slider
- Background music controls
- Windows startup support
- Image caching
- Multiple store support

### Improved

- Main application interface
- Giveaway claiming workflow
- Store panels
- Theme handling
- Audio handling
- Image handling
- Persistent local state

### Fixed

- Giveaway URL fallback
- Audio fade handling during splash screen closing
- Theme color synchronization
- Volume control UI
